Download

YTFast runs on Windows and on Macs with Apple Silicon. Builds are published on GitHub.

Free builds come as a zip You download a zip from the project's newest build on GitHub, which needs a free GitHub account. The step-by-step guide walks you through it. Ready-made installers and automatic updates are part of YTFast Pro.

Mac with Apple SiliconYTFast-for-MacChrome, Firefox, Edge, Brave or Safari

On Windows, Chrome, Edge and Brave lock their sign-in data so that other programs cannot read it. That is why YTFast needs Firefox there.

What you will need

  • A YouTube Music Premium account.
  • A browser signed in to music.youtube.com with that account.
  • About 250 MB of disk space. On first run YTFast downloads two helper programs, yt-dlp and Deno.
  • An internet connection.

The first run

  1. Sign in to music.youtube.comDo this in your browser first. YTFast uses that sign-in.
  2. Open YTFastWindows and macOS warn you the first time, because YTFast is not signed with a paid certificate. The guide shows how to continue.
  3. Choose your browserYTFast reads YouTube's sign-in from it, then fetches its helper programs. This takes a minute or two and happens once.
  4. PlayAfter that, songs start in about a second.

Build it yourself

YTFast is written in Rust. Clone the repository and run cargo run -p ytfast. To look around without an account, run cargo run -p ytfast -- --demo.
